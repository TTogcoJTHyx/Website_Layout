# NOVA — простой шаблон магазина

## Как запустить

`fetch()` не загружает JSON при двойном клике по HTML-файлу в большинстве браузеров. Откройте папку через простой локальный сервер, например расширение **Live Server** в VS Code. Затем перейдите на `index.html`.

## Архитектура

- `index.html`, `catalog.html`, `product.html`, `cart.html` — структура страниц.
- `css/` — внешний вид. `css/themes/default.css` содержит все главные переменные темы.
- `js/storage.js` — одно место для чтения и записи товаров, корзины и заказов.
- `js/main.js` — общие элементы: шапка, подвал, карточка товара, формат цены.
- `js/catalog.js`, `product.js`, `cart.js`, `admin.js` — логика конкретных страниц.
- `data/store.json` и `data/products.json` — начальные данные.

## Как данные проходят через сайт

1. При первом запуске `loadProducts()` читает `data/products.json`.
2. После изменения в админке товары сохраняются в LocalStorage.
3. В следующих запусках LocalStorage имеет приоритет — поэтому данные не сбрасываются.
4. Каталог, карточка товара и админка всегда вызывают `loadProducts()`, а не знают, откуда конкретно получены данные. Позже эту функцию можно заменить на запрос к backend.

## Как сделать новый магазин за 15 минут

1. **Название и описание:** измените `data/store.json`.
2. **Цвета:** откройте `css/themes/default.css` и измените значения `--color-*`.
3. **Шрифты:** в том же файле измените `--font-main` и `--font-heading`.
4. **Логотип:** замените файл в `assets/logo/` и укажите путь в поле `logo` файла `store.json` (сейчас логотип текстовый в шапке, путь подготовлен для будущей замены).
5. **Товары:** замените массив в `data/products.json`. Новый товар также можно создать через `admin/products.html`.
6. **Категории:** категории выводятся из поля `category` товаров. Для красивого русского названия добавьте соответствие в `categoryTitle()` внутри `js/main.js`.
7. **Контакты:** телефон, почту и ссылки соцсетей поменяйте в `data/store.json`.
8. **Новая тема:** скопируйте `css/themes/default.css`, например как `css/themes/luxury.css`, измените только переменные и подключите новый файл вместо `default.css` во всех HTML-страницах. JavaScript менять не нужно.

## Что изучить сначала

Сначала посмотрите `data/products.json`, затем `js/storage.js`, `js/main.js` и `js/catalog.js`. После этого будет проще понять страницу товара, корзину и простую админку.

## Важно про demo-админку

Эта админка полезна для обучения, макета и MVP: она хранит изменения только в браузере текущего пользователя. У неё нет авторизации, общей базы данных, защиты данных и реальной отправки заказа. Для настоящего магазина нужен backend с базой данных, безопасной авторизацией, API, обработкой оплаты и серверной валидацией.
